Raw TCP demonstration

An educational socket-level protocol with length-prefixed framing. It is not used by the web app for authentication.

EDUCATIONAL SIMULATION

Protocol

CLIENT HELLO|CLIENT001 SERVER WELCOME|CLIENT001 CLIENT AUTH|D0001|demo-pass SERVER AUTH_OK CLIENT VOTE|1|REQ-... SERVER VOTE_ACK|TX CLIENT QUIT SERVER BYE frame = [4-byte big-endian length][UTF-8 payload]

Run standalone: python -m backend.networking.tcp_demo_server --port 9000 then python -m backend.networking.tcp_demo_client --port 9000.

Run it

Starts a real TCP server on 127.0.0.1 (random free port), connects a client and exchanges framed messages. Then runs the framing experiment.
